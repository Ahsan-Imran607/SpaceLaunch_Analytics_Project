# 🚀 Space Launch Analytics

An ETL and Exploratory Data Analysis (EDA) project focused on collecting, processing, and analyzing historical space launch data.

## Features
- Extract historical launch records using a public API.
- Clean and transform raw JSON data using Pandas.
- Validate records and handle missing or duplicate data.
- Store processed data in an SQLite database and CSV files.
- Perform EDA to identify launch trends and patterns.
- Explore insights through an interactive Streamlit dashboard.

## Technologies
- Python
- Requests, Pandas, NumPy
- Pydantic
- SQLite
- Jupyter Notebook
- Plotly
- Streamlit

## Run Locally

```bash
git clone https://github.com/YOUR_USERNAME/SpaceLaunch_Analytics.git
cd SpaceLaunch_Analytics
pip install -r requirements.txt
streamlit run app.py
```
